## Install

### Browser (Tampermonkey / Violentmonkey)

1. Install [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Install from **[Greasy Fork](https://greasyfork.org/en/scripts/{{GREASYFORK_ID}}-{{GREASYFORK_SLUG}})**. You get automatic updates that way.
3. Confirm the install. Open {{PAGE_NAME}} and you are done.

The raw file on GitHub also works as an install link if you prefer: [{{SCRIPT_SLUG}}.user.js](https://raw.githubusercontent.com/tulpn/{{SCRIPT_SLUG}}/main/{{SCRIPT_SLUG}}.user.js)

### Torn PDA

1. In Torn PDA go to **Settings → Userscripts → Add**.
2. Paste this URL and save:
   `https://update.greasyfork.org/scripts/{{GREASYFORK_ID}}/{{GREASYFORK_SLUG}}.user.js`
3. Open {{PAGE_NAME}} inside the app.

No API key is needed. The script never asks for one and never makes a network request.

## Development and tests

The script is tested against a fake page in [jsdom](https://github.com/jsdom/jsdom) using Node's built-in test runner.

```powershell
npm install
npm test
```

`npm test` first syntax-checks the userscript, then runs everything in `test/`. The same command runs in GitHub Actions on every push and pull request.

### Security notes

- The settings panel is built with DOM calls only. There is no `innerHTML`, so stored text can never become markup.
- Everything read from storage is treated as untrusted and normalised field by field; unknown keys are dropped. This matters because localStorage on torn.com is shared with every other script you run.
- The script makes no network requests, uses no `GM_*` functions, and runs with `@grant none`.
