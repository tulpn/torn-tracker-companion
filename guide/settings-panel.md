> **Test release.** The companion is in public testing. Things may change before version 1.

**Core:** free for everyone.

Open it with the round ⚙ button in the bottom right corner of any Torn page. Your changes
are kept while you move between tabs, and take effect when you press **Save**.

## Features

A switch for each feature, grouped by wave, and its options where it has some: for
example how the war page sorts opponents, or how much the price filler undercuts the
market. A feature that's off doesn't run at all.

## Sharing

A switch for each kind of data the companion can share, every one off to start with. See
[Choose what to share](what-is-shared.md). This tab also shows what's waiting to be sent
and, if sharing has stopped, why.

## Keys

- **Script key:** your torn-tracker.com [script key](website:script-key.md). It isn't a
  Torn API key, it's kept only on this device, and it's never written to the console.
- **Forget me:** clears everything the script keeps on this device. See
  [Forget me](forget-me.md).
