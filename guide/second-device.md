> **Test release.** The companion is in public testing. Things may change before version 1.

**Core:** free for everyone.

## Install it on the other device

Follow [Install on desktop](install-desktop.md) or [Install in Torn PDA](install-pda.md),
whichever you don't have yet.

## Use the same script key

Paste the same [script key](website:script-key.md) into the **Keys** tab there. One key
works on any number of your devices. If you'd rather tell them apart, create a second
key on torn-tracker.com: you can revoke either one on its own.

## Settings are per device

Each install keeps its own settings: which features are on, what you share, your key.
Switching a sharing kind on in PDA doesn't switch it on in your browser. Set each one up
the way you want it.
